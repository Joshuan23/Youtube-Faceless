Before you can connect, you need a free Google OAuth file (client_secrets.json). This is a 5-minute one-time step.
1

Go to console.cloud.google.com and create a new project (any name).

2

In the search bar type YouTube Data API v3, open it, and click Enable.

3

Go to APIs & Services → OAuth consent screen. Choose External, fill in the app name + your email, and under Test users add your own Google email.

4

Go to Credentials → Create Credentials → OAuth client ID. Choose application type Web application (NOT Desktop).

5

Under Authorized redirect URIs, click + ADD URI and paste this exactly:

6

7

In Replit, open the credentials/ folder and upload client_secrets.json there. Then refresh this page.
